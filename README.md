# MAPLE-Tutorial

Example files for the MAPLE ParmFit tutorials, one directory per route: `parmfit/refinement`, `parmfit/ncaa`, and `parmfit/metalaa`. Every file here is copied from the verified tutorial runs; the ParmFit tutorial pages on the [MAPLE-Website](https://github.com/AmiHaruka/MAPLE-Website) link to these files directly.

The complete run archives (per-case zips including every `_work/` directory) are on Zenodo:

- Refinement: [10.5281/zenodo.23126271](https://zenodo.org/records/23126271)
- NCAA: [10.5281/zenodo.23126301](https://zenodo.org/records/23126301)
- MetalAA: [10.5281/zenodo.23126309](https://zenodo.org/records/23126309)
